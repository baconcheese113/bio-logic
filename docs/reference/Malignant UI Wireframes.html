What we're trying to figure out

Four genuinely different answers to the same five UI questions. Same mid-game moment in every exploration: two engulfments in progress, a Genome Leakage timer running, a PCR/Gel chain mid-run, flow cytometer reading an incoming wave.

Pick a philosophy before pixel-pushing. We're voting on information architecture, not skins.

The five uncertainties

  1. Chemoattractant markers — fading, three colors, plus permanent beacons. How to read without noise?
  2. Instrument chain during live combat — 50–100s of attention while the map keeps killing units.
  3. Flow cytometer scatter plot at RTS pace, including ghost-label teaching moment.
  4. Staged engulfment — 8–12s reaction window across many tiny units.
  5. Genome Leakage alert urgency + log — critical, but alert spam kills RTS.

ADiegetic minimalism

Argument: the player reads the world, not the UI. Every alert, every status, every chain step is a visible state of an object on the hex grid. Only the plasmid editor lives in chrome. If you can see it in the tissue, we don't show it in a panel.

Annotations

  1. Markers as tile glows. Volatile markers fill the hex tile itself with a soft color wash. Remaining time shown as a tiny "↓ 6s" inside the tile, visible only when zoomed. Beacons are a solid icon + steady aura ring — no time, no fade. at full zoom-out, marker tiles look like terrain tint; player relies on minimap color-coding.
  2. Instrument chain is the buildings. PCR shows a fill bar + bubbles directly on its sprite ("PCR · 80%"). Gel sits idle and dim until input arrives. No popup. To inspect, hover or click the building. player must look at the map to read chain progress — fine when zoomed in, easy to miss across a big base.
  3. Cytometer projects onto the world. The Flow Cytometer Tower casts a faint "lens cone" onto the hexes around it; scatter clusters render as floating dot constellations next to the tower with ghost labels until learned, then labels fade. limited screen area; can't compare two cell types side-by-side without panning.
  4. Engulfment = pulsing alarm ring. Orange dashed ring while < 50% complete, red pulsing ring after. Engulfment % rendered next to the unit. Response is verbs the player already uses — paint defend/retreat on the tile. three simultaneous engulfments in dense terrain = ring soup; no "jump to next crisis" hotkey.
  5. Genome Leakage = DNA escaping rubble. A glowing DNA strand drifts up from the destroyed building, ringed by a shrinking countdown arc. The countdown is at the rubble — to read it you look where the loss happened. Log = the rubble itself (it persists). No global alert toast. if you weren't looking at that part of the map when it died, you miss the start of the timer. Critical.

What breaks this

Late tier-3, with 4+ simultaneous engulfments, two leakage timers, three congested channels, and an instrument run mid-disambiguation — the world is too dense to read at god-view. Player ends up panning constantly. Diegesis stops being elegant and starts being fog.

BSplit attention management

Argument: a cancer cell is a tactical unit; a plasmid is a lab artifact. These are two activities and they deserve two screens. Left = battlefield, right = lab dashboard, always visible. The player's eyes literally move between them like a real bench scientist moving between microscope and benchtop.

Annotations

  1. Markers stay on the map. Same tile-glow treatment as A — but now the lab dashboard owns the screen real estate, so the map can be denser without competing chrome. Cleaner mid-zoom. a 60% map is a 60% map; small-screen players lose tactical resolution.
  2. Instrument chain is a persistent strip. PCR → Gel → Book → Editor cards always visible in upper right. Click a card to focus that pane. No popups, no switching screens, no losing the battlefield. always-on costs pixels; new players see a full dashboard before they understand any of it.
  3. Cytometer is a permanent widget with axes pinned. Ghost labels appear as dashed boxes over unidentified clusters; they dissolve once the chain confirms identity. No "open" action — it's just there, glanceable. multiple towers compete for one widget; needs a tower selector dropdown.
  4. Engulfments still ring on map, but the dashboard also lists "active threats" — click jumps camera. RTS commander's instinct: hear the alarm, see the list, jump. two places for the same event = potential desync confusion if list lags.
  5. Leakage = a dedicated red panel in the dashboard with countdown + one-click "swap plasmid / open counter chain / pan to site". Log lives just below — always visible, always scrollable. looks alarming even when nothing's wrong; the empty state of this panel must feel calm, not absent.

What breaks this

The split is rigid. If a single moment needs the full map (a wide pincer attack across the entire tissue), 40% of the screen is "the wrong thing right now" — and you can't reclaim it. Also, two cytometer towers + ELISA + Leakage panel + Editor will not all fit cleanly; the dashboard becomes a tab carousel, which is the problem split was supposed to solve.

CContextual expansion

Argument: UI is invisible until you ask. Default view is hex grid + a thin status strip. Click a building, a panel grows from it. Click away, it collapses. Toast notifications fly into a corner; clicking expands them into the full log. The player chooses when to spend attention on chrome.

Annotations

  1. Markers in-world, status in strip. Same tile-glow markers as A/B. The thin top strip surfaces only aggregate state ("18 units · inflammation level"). Beacons live on the map, never in chrome. aggregate stats can't be trusted at a glance — "are my markers working?" requires looking at the actual tiles.
  2. Click PCR → it grows the chain panel, tethered visually to the building it came from. The panel is the chain. Click outside, it folds. The instrument chain only exists when you're using it. a 50-second PCR run means the panel needs to stay open or you don't see results; players will leave panels open and recreate B accidentally.
  3. Cytometer = peek label + click to expand. Hovering the tower shows the headline ("macroph + NK"). Click to grow the full scatter panel. Ghost labels live inside the expanded view. hover-driven intel feels slow in a panicked moment; needs a hotkey.
  4. Engulfments = toast stack, not popups. Each engulfment posts a small card in the corner with %, unit id, and "jump ↗". Click jumps camera. Stack is capped — older threats compress into a count badge. in a chaos moment, the toast stack scrolls; you read percentages, not the map.
  5. Leakage = critical toast with shrinking arc. Always at the top of the stack. Click expands the full leakage log + "swap / counter / pan" actions. The toast is dismissible only by acting. if you don't click it, it just sits there, eating attention and corner pixels until expiry. Anxiety design.

What breaks this

Late game has too many "I want this open" panels. Players pin the chain, pin the cytometer, pin the leakage log — and rediscover the split layout (B), but worse, because every pinned panel has its own arbitrary position and shadow. The discipline of "click to dismiss" breaks the moment two crises happen at once.

DOverlay system (ONI-inspired)

Argument: the map is the UI. The player toggles overlay modes — chemistry, metabolism, threat, intelligence — like switching microscope filters. Each mode repaints the same hex grid through a different lens. Default view = clean tissue. Multi-overlay = decision time.

Annotations

  1. Markers live in the chemistry overlay. Default view shows them faintly. Toggle "chem" [1] to bloom them — full gradients, beacon fields, evaporation halos. Three colors stay separable because the overlay dims everything else. if the player forgets to flip on chem, painting feels like working blind. Discoverability of overlays = a tutorial problem.
  2. Instrument chain = a always-on pill in the corner + an expanded panel when you press [E] or click the pill. Chain isn't an overlay — it's the one piece of "lab" chrome that survives because it has no spatial expression on the map. violates the "everything is a lens" purity — chain is special-cased. Players will ask why.
  3. Intel overlay paints cytometer halos on the map showing each tower's coverage radius, with a floating scatter card pinned next to the tower. Ghost labels float inside the card while unidentified, fade when learned. in dense bases with many towers, halos overlap into mud; needs a "selected tower only" sub-mode.
  4. Threat overlay = red hatched zones + crosshair-tagged engulfments. Color of crosshair encodes urgency (yellow <50%, red ≥50%). Players cycle to threat overlay when they hear an engulfment SFX. if threat overlay isn't on, engulfments are easy to miss — relies on audio cue + muscle memory for [3].
  5. Leakage = top-edge banner always visible regardless of overlay (it's chrome, not a lens), plus a glowing arc rendered on the destroyed building tile itself when threat overlay is on. Log opens with [L]. the only piece of UI that ignores the overlay system — could feel inconsistent. Argument for inconsistency: it's the one thing you can never afford to miss.

What breaks this

Overlays are great for spatial information. They're terrible for temporal information — a 42s leakage timer doesn't belong on a hex tile. The system slowly leaks chrome (the chain pill, the leakage banner, the top status strip) until you realize half the screen is a fixed HUD pretending to be an overlay framework. ONI handles this by accepting both layers; we'd need to too.
